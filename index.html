A simple application to help users manage their money.

1. Product Name

2. Team Members

3. Application Overview

BudgetBuddy is a Java desktop application that helps users manage their expenses and stay within a budget. Users can enter expenses, organize them by category, view their total spending, and see how much money they have left in their budget.

4. Technology Overview

  • Java - Main programming language
  • Java Swing - Graphical user interface
  • Object-oriented programming - Organizing the application into classes
  • File handling - Saving expenses for future use
  • Visual Studio Code - Development environment
  • GitHub - Version control and source code storage

6. Feature List

  1. Add expenses with a name, amount, and category.
  2. Display expenses in a table or list.
  3. Calculate total expenses.
  4. Set a budget and calculate the remaining balance.
  5. Delete expenses from the list.
  6. Save expenses to a file.
